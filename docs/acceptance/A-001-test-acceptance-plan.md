# mallchat-taro 测试验收文档

## 1. 测试范围

### 1.1 功能测试

| 模块 | 测试项 | 优先级 |
|------|--------|--------|
| 用户登录 | 微信登录、Token 刷新、退出登录 | P0 |
| 消息列表 | 会话列表、未读数、搜索、置顶、删除 | P0 |
| 聊天功能 | 发送消息、接收消息、图片发送、消息撤回 | P0 |
| 联系人 | 好友列表、搜索、添加好友、好友分组 | P0 |
| 群聊管理 | 创建群聊、群详情、邀请/退出/解散 | P0 |
| 通知中心 | 系统通知、标记已读 | P1 |
| 个人中心 | 用户信息、编辑资料 | P1 |
| 好友动态 | 动态列表、图文展示 | P2 |

### 1.2 非功能测试

| 测试类型 | 测试项 | 优先级 |
|----------|--------|--------|
| 性能测试 | 页面加载时间、接口响应时间 | P1 |
| 兼容性测试 | 微信/支付宝/抖音小程序 | P1 |
| 稳定性测试 | 长时间运行、大量消息 | P1 |
| 安全测试 | Token 安全、数据加密 | P1 |

## 2. 测试用例

### 2.1 用户登录测试

**TC-001: 微信登录成功**

- **前置条件**: 用户已安装微信
- **测试步骤**:
  1. 打开小程序
  2. 点击登录按钮
  3. 确认微信授权
- **预期结果**: 登录成功，显示用户信息
- **优先级**: P0

**TC-002: Token 过期重新登录**

- **前置条件**: 用户已登录，Token 已过期
- **测试步骤**:
  1. 等待 Token 过期
  2. 执行需要认证的操作
- **预期结果**: 自动重新登录，操作成功
- **优先级**: P0

### 2.2 消息列表测试

## 3. 验收标准

- [ ] 所有 P0 测试用例通过

- [ ] 首屏加载时间 < 2 秒

- [ ] 微信小程序正常运行
- [ ] 支付宝小程序正常运行
- [ ] 抖音小程序正常运行

- [ ] Token 安全存储

- [ ] 敏感信息不泄露

## 5. Bug 管理

### 5.1 Bug 严重程度

| 程度 | 说明 | 处理时间 |
|------|------|----------|
| P0 | 阻塞性问题，无法使用 | 立即修复 |
| P1 | 严重问题，影响主要功能 | 24 小时内 |
| P2 | 一般问题，影响次要功能 | 3 天内 |
| P3 | 轻微问题，不影响使用 | 1 周内 |

### 5.2 Bug 处理流程

1. **提交 Bug**: 记录 Bug 详情、复现步骤、截图
2. **分配 Bug**: 指派给对应开发人员
3. **修复 Bug**: 开发人员修复并提交代码
4. **验证 Bug**: 测试人员验证修复效果
5. **关闭 Bug**: 验证通过后关闭 Bug
